# Prenomal Website (Starter)

This folder contains a static, responsive starter website for Prenomal.

## Goal and scope
- **Purpose:** present Prenomal and convert website visitors into enquiries.
- **Target users:** potential customers, existing clients, and business partners.
- **Pages included:** Home, About, Services, Gallery, Contact, and Privacy section.
- **Core features included:** responsive navigation, gallery placeholders, and client-side contact-form validation.

## Run locally
Open `/website/index.html` in a browser, or serve the repository root with a static server.

## Replace placeholder content
Update text, contact details, service cards, and gallery tiles in `index.html`.
